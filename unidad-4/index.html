1Qué es un sistema de ecuaciones

Son dos ecuaciones con dos incógnitas (x e y) que se tienen que cumplir al mismo tiempo. Se escriben con una llave:

x + y = 5x − y = 1

La solución es un par de números (x ; y) que hace verdaderas las dos ecuaciones. Acá es (3 ; 2):

3 + 2 = 5 ✓3 − 2 = 1 ✓

El par (4 ; 1) cumple la primera (4 + 1 = 5) pero no la segunda (4 − 1 = 3, no 1). Entonces no es solución.

Verificar es reemplazar x e y en las DOS ecuaciones. Si falla una, no es solución.

2Despejar y: la forma y = mx + b

Casi todo en esta unidad arranca dejando la y sola de un lado. Así queda la ecuación de una recta, con su pendiente m (el número que multiplica a x) y su ordenada b (el número suelto).

2x + y = 7y = −2x + 7El 2x pasa restando. Pendiente −2, ordenada 7.
3y − 6x = 93y = 6x + 9y = 2x + 3El −6x pasa sumando y después se divide TODO por 3. Pendiente 2, ordenada 3.

Al dividir por el número de la y, se dividen todos los términos, no solo uno.

3Método gráfico

Cada ecuación es una recta. La solución es el punto donde se cortan.

  1. Despejar y en las dos ecuaciones.
  2. Graficar cada recta: se marca la ordenada en el eje y, y desde ahí se usa la pendiente (pendiente 1 = subo 1, avanzo 1; pendiente −1 = bajo 1, avanzo 1).
  3. Leer el punto de corte y verificarlo en las dos ecuaciones.

y = x + 1y = −x + 5

4Clasificación de sistemas

Dos rectas pueden cortarse en un punto, ser paralelas o ser la misma recta. Cada caso tiene un nombre:

PendientesOrdenadasLas rectas…Sistema

IgualesIgualescoincidenCompatible indeterminado

Para clasificar sin resolver: despejar y en las dos y comparar m y b.

x + y = 1 → y = −x + 1y + x = 4 → y = −x + 4Misma pendiente (−1), distinta ordenada (1 y 4): paralelas → incompatible.

“Compatible” = tiene solución. “Determinado” = una sola.

5Método de igualación

Se despeja la misma letra en las dos ecuaciones y se igualan.

x + y = 5x − y = 1

1. Despejo y en las dos:y = 5 − x y = x − 1 2. Igualo lo que quedó:5 − x = x − 1 3. Resuelvo la ecuación de una incógnita:5 + 1 = x + x → 6 = 2x → x = 3 4. Reemplazo x en cualquiera de los despejes:y = 3 − 1 = 2 5. Respuesta y verificación:(3 ; 2) → 3 + 2 = 5 ✓ 3 − 2 = 1 ✓

6Método de sustitución

Se despeja una letra en una ecuación y se reemplaza en la otra. Conviene despejar la letra que está sola, sin número adelante.

x + 2y = 73x − y = 7

1. Despejo x en la primera:x = 7 − 2y 2. La reemplazo en la segunda, con paréntesis:3 · (7 − 2y) − y = 7 3. Distributiva y resuelvo:21 − 6y − y = 7 → −7y = −14 → y = 2 4. Vuelvo al despeje:x = 7 − 2 · 2 = 3 5. Respuesta y verificación:(3 ; 2) → 3 + 4 = 7 ✓ 9 − 2 = 7 ✓

El paréntesis al reemplazar no se olvida nunca: 3 · (7 − 2y), no 3 · 7 − 2y.

7Método de reducción (sumas y restas)

Está en el programa aunque el cuadernillo no tiene ejercicios de este método. Se suman o restan las dos ecuaciones para que desaparezca una letra.

x + y = 10x − y = 4

Sumo las dos ecuaciones: la y se va porque hay +y y −y. (x + y) + (x − y) = 10 + 4 → 2x = 14 → x = 7 Reemplazo en la primera:7 + y = 10 → y = 3

Si ninguna letra se cancela sola, se multiplica una ecuación antes:

2x + y = 8x + 3y = 9 → la multiplico por 2 → 2x + 6y = 18 Resto: (2x + 6y) − (2x + y) = 18 − 85y = 10 → y = 2 → 2x + 2 = 8 → x = 3

8Qué pasa al resolver un sistema SCI o SI

Si el sistema no es determinado, al resolver se van las dos letras y queda una igualdad entre números:

Queda…EjemploSistema
algo verdadero0 = 0Compatible indeterminado (infinitas soluciones)
algo falso0 = 5Incompatible (sin solución)

No es un error de cuentas: es la respuesta. Se escribe la clasificación.

9Problemas con sistemas

  1. Elegir qué es x y qué es y, y escribirlo.
  2. Armar una ecuación con cada dato. Casi siempre hay una de “cantidades” y otra de “plata”, “patas” o “puertas”.
  3. Resolver con el método que quieras.
  4. Responder con una oración.

Ejemplo. “Un alfajor y una gaseosa cuestan $2100. Tres alfajores y dos gaseosas cuestan $5400. ¿Cuánto cuesta cada cosa?”

a = precio del alfajor, g = precio de la gaseosa a + g = 2100 3a + 2g = 5400 Sustitución: g = 2100 − a 3a + 2 · (2100 − a) = 5400 → 3a + 4200 − 2a = 5400 → a = 1200 g = 2100 − 1200 = 900 El alfajor cuesta $1200 y la gaseosa $900.

✗Errores típicos

  • Verificar en una sola ecuación. Tiene que dar en las dos.
  • Olvidar el paréntesis al sustituir. Después la distributiva sale mal.
  • Dividir solo un término al despejar. 3y = 6x + 9 → y = 2x + 3, se divide todo.
  • Encontrar x y no buscar y. La solución es el par (x ; y).
  • Pensar que 0 = 0 es un error. Quiere decir infinitas soluciones.
  • Confundir los nombres. Compatible = tiene solución. Incompatible = no tiene.
